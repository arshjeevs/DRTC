# lerobot_policy_groot_n15

GR00T N1.5 as a LeRobot 0.7 policy plugin (LeRobot removed GR00T N1.5 after 0.5.1). Ported from the minor's fork,
with guided RTC (`supports_rtc`; tested in `tests/test_groot_n15_rtc.py`). LeRobot finds it by its distribution name
(`lerobot_policy_*`); installed with the repo's `uv sync`. GR00T N1.7 is LeRobot's own `groot` policy.
