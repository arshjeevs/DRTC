Install: laptop `uv sync --extra gpu --extra sim` (and `uv pip install matplotlib` for the report); H200 container `uv sync --frozen --extra gpu --extra sim --python /usr/bin/python3`; **A100 `lab/bin/a100-setup` only** (a plain `uv sync` there installs CUDA 13 builds its driver cannot run); Pi `lab/bin/pi-setup` (CPU PyTorch). Then `source .venv/bin/activate` and `lab ...`, or `.venv/bin/lab ...`.

| Command | Does |
|---|---|
| `lab list`, `lab check [--rig] [--data [--online]]` | registry; devices and calibration; dataset pins |
| `lab record <name> --task "..."` | record `<name>_raw` with the leader arm, check, trim into `<name>`, push both, registry entries |
| `lab trim <raw dir> <out dir>` | trim the idle start/end of every episode into a new dataset |
| `lab train <model> [--steps N] [--resume] [--push CKPT]` | train a registry model with LeRobot 0.7 (clean stop: Ctrl-C or `lab stop <model>`) |
| `lab submit <model> --host h200`, `lab worker`, `lab jobs` | queue jobs pinned to a pushed commit; run them when the GPU has room |
| `lab serve <model>` | serve a model with LeRobot 0.7's policy server (deployment from the registry) |
| `lab eval list\|check\|freeze\|serve\|servers\|run\|void\|status\|push\|pull\|report\|offline` | official evaluations, the bench and the offline evaluation ([WORKFLOW.md](WORKFLOW.md) parts 2-3, [docs/EVALUATION.md](docs/EVALUATION.md)); `lab eval serve --for-pi` on the laptop serves the Pi |
| `lab run <experiment> [--model M] [--robot rig\|replay]` | one test run (drtc engine: DRTC scheduling, cooldown re-request, faults, smoothing), in results/scratch |
| `python -m drtc.evals.stack` | the final smoothing stack from the E3a bench (the fixed rule) |
| `lab results [--experiment E]` | stalls, chunks, turnaround, faults, recoveries per run |
| `lab calibrate follower\|leader`, `lab rig <key>` | calibration with the rig's explicit file; rig values for scripts |
| `lab import-results <old results dir>` | copy the minor's results in, with the new model names |

`lab run` (a single run, outside an eval) writes to `results/scratch/<date>/<experiment>/<model>/<run_id>/` (config.yaml, ticks.csv with `plan.*`, chunks.csv, faults.csv, recovery.csv, run.json, rollout.log). Official trials: `results/evals/<eval>/` (WORKFLOW.md, Part 2). The robot computers (laptop, Pi) keep the phone camera bridge (`lab/bin/phonecam`) and the tmux session (`lab/bin/session`).
